Capture rules:
- One capture per New or Rework block at least; Later blocks get one when it helps the client see what to supply.
- Crop to the block the caption talks about (`data/crop.py`). Stitch a block that spans two scroll positions.
- A capture of a hover state says so in the caption.
- Paint out the pointer on flat backgrounds; blur personal contact details.
- Every figure has a source line: the page address and the capture month.

# Channel benchmark

Sample: the most-viewed recent videos and live streams on large public B2B and tech channels, with a separate
cut for videos of 20 minutes or longer. The channels whose patterns are described below: IBM Technology, Google
Cloud Tech, Microsoft Developer, Gartner, Semrush and Ahrefs. Figures are rounded. Re-sample a handful of
channels in the client's own category when the numbers matter for a decision.

| Measure | All videos | 20 min or longer |
|---|---|---|
| Median description length | about 1,650 characters | about the same |
| Carry 3+ timestamps (chapters) | about half | slightly more than half |
| Median links | about 4 | |
| Use hashtags | about 6 in 10 | |
| Median first line | about 170 characters | |
| Subscribe call to action | about a quarter | |
| Median metadata tags | about 5 | |

## Patterns by channel

- **IBM Technology**: a "learn more" link to the product on line 1, a 2 to 3 sentence summary naming the
  presenter, a dozen or so verb-led chapters, a newsletter link, an AI-disclosure line, a few hashtags, a footer
  of sibling channels.
- **Microsoft Developer (interview shows)**: a question hook naming the speaker and role, a context paragraph, a
  "what you'll learn" list of about 6 bullets, a speaker block, a long run of chapter markers, a resources and
  links block with docs, a subscribe line, a few hashtags.
- **Gartner (podcast-style episodes)**: a one-line hook, event or research links, an episode paragraph with the
  analyst's name and title, "you'll learn" bullets, timestamps, previous episodes, playlist, subscribe, an About
  block.
- **Semrush**: a tool call to action on line 1, a time-boxed promise ("In N minutes, learn ..."), a "what's
  covered" list, assets and links, many chapters, subscribe and academy links, a few hashtags, and 11 to 15
  specific metadata tags.
- **Google Cloud Tech**: resource links first, an episode summary, "watch along and learn" bullets, chapters, a
  question of the day, resources, then speaker and products-mentioned lines, 5 to 10 hashtags.
- **Ahrefs**: a one-line hook with a number, related videos, then long, number- and name-rich prose. Strong for
  AI quoting, weak for scanning.
- **Customer-story sessions on enterprise software channels**: a customer-story hook question, the customer's
  speakers named with titles, learn-more links, an About block.

The template keeps the elements most of these share (hook, one link up top, summary, bullets, chapters, speakers,
resources, hashtags) and adds an explicit answer paragraph for AI engines (the Ahrefs and IBM prose style, made
short).

# Exemplar library: figures per block

Figures for the block notes of an extended build (`reference/doc-structure.md`), keyed by the block number and name in `data/packed_vs.py`, each from a page in the published benchmark set. Nothing here is a capture: each line says what the figure should show. Capture it fresh in the browser (recipe in `reference/lean-doc.md`), crop it with `data/crop_map.py`, check that the page still shows the pattern, and write the caption from the crop, not from this line.

Caption pattern: the site, then what the crop shows in one sentence, in your own words and with no quoted page copy. Then a Source line: domain/path, Month Year of your capture.

# Site index: one-rival comparison pages ({Company} vs <Rival>)

The 12 published comparison pages behind this skill: 9 by SaaS leaders and 3 by vendors in other industries, all on the vendors' own sites. Section type ids refer to `reference/section-types.md`; blocks to `reference/section-model.md`; figures to `reference/exemplar-library.md`.

How to use it: start from the leaderboard to see which sites had the best ideas, open a site's entry for the page address, the section types it is the named best example for and the types it carries, then read its notes before re-reading the live page. Pages change: re-check anything before you reuse it. Trust patterns no vendor here shows (disclosure, method, change log) come from independent review sites in general; pick one in a category unrelated to the client when you need a capture.
